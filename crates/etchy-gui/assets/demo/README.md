# Demo board — Mad_RP2040

The `old/` and `new/` folders hold a Gerber + Excellon fab pack for two
revisions (v0.0.0 → v0.0.1) of **Mad_RP2040**, an open-source RP2040 board:
<https://github.com/Cimos/Mad_RP2040>. It is the project author's own board,
included here with permission as bundled demo data so the viewer and the
`etchy <old> <new>` quickstart work straight after a clone.

- Exported from KiCad 9.0.7 (Pcbnew).
- Used only as sample input — not linked into or compiled with any binary
  beyond being embedded as demo assets (`include_dir!`).
- Redistributed under the same terms as its source repository.

To diff a different (e.g. confidential) board locally without committing it,
see the `git update-index --skip-worktree` note in the repo-root `.gitignore`.
